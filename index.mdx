Smart Mess is a complete management platform for mess and tiffin businesses. Owners publish daily menus, manage subscription plans and one-time orders, track deliveries, confirm payments, and analyze customer feedback — all from a single dashboard. Customers browse menus, order food, skip or pause meals, pay via QR or cash, and review their experience.

## Get started

<Steps>
  <Step title="Clone and install">
    Clone the repository and install backend and frontend dependencies. The backend uses Python 3.12 + FastAPI; the frontend uses React + Vite.
  </Step>
  <Step title="Configure environment">
    Copy `backend/env.example` to `backend/.env` and set `DATABASE_URL` and `SECRET_KEY`. SQLite works out of the box for local development.
  </Step>
  <Step title="Run migrations and seed">
    Run `python -m app.migrate upgrade` from the `backend` directory, then optionally seed demo data with `python backend/seed_preview.py`.
  </Step>
  <Step title="Start the app">
    Start the backend with `uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8001` and the frontend with `npm run dev` inside `frontend/`. Open `http://127.0.0.1:5173`.
  </Step>
</Steps>
